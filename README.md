# Student-City-Companion
Student City Companion is a full-stack MERN web application that helps students find and manage PG accommodations. Users can browse PG listings, view details, upload images, add reviews and ratings, save favorites, book PGs, and manage their own listings through a secure JWT-based authentication system.
# Student City Companion

A web application that helps students find and manage PG accommodations.

## Features

- User Authentication
- PG Listing
- Add/Edit/Delete PG
- Favorites
- Booking Management
- Dashboard

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB

## Installation

### Frontend

cd frontend
npm install
npm start

### Backend

cd backend
npm install
npm start
